# arma3_missions
This is some content modding (object compositions and multiplayer missions) including scripts of AI for the game Arma 3. 
Simply copy these files in your profile folder (usually in "C:/Users/YOUR USERNAME/Documents/Arma3")

Check my workshop mods in [Dork's Arma3 Workshop](https://steamcommunity.com/id/dber/myworkshopfiles/?appid=107410) and gameplays in [pcgamin's youtube playlist](https://www.youtube.com/playlist?list=PLiejaJiVq8HD_B1AAd9ZZBopjGj8ns-ce)

## Features

### 🎭 **Factions**
- **USEC** - US/NATO forces
- **BEAR** - Russia/CSAT forces  
- **SCAV** - Independent/Guerrilla forces
- **Civilians**

### 📊 **Points Mechanics**
- **Rating**
  - +1000 per civilian kill
  - +2000 per opponent survivor kill
  - -500 for friendly fire

- **Money**
  - +500 per civilian kill
  - +1000 per opponent survivor kill
  - -500 for friendly fire

- **Kill Count** tracking
- **Alive players** counter (survivors and civilians)

### 🚁 **Timeout Extraction Mechanics**
*Use radio channels 0-8*
- **Support Loot Drop**
- **Helicopter Transport**

### 🔮 **Teleport Mechanics**
- **[Cyan]** Transport Ticket to Civilian Plane (items to storage)
- **[Red]** Teleport to roam around city or select random position
- **[Orange]** Teleport to hunt survivor player/NPC (USEC, BEAR, Rogue, SCAV)
- **[Dark Orange]** Teleport to hunt civilian player/NPC

### 🎒 **Personal Arsenal Mechanics**
- **Custom Lock Box** - Carriable, lockable, and unlockable
- **Virtual Arsenal** with Lock Box Contents
- **Virtual Arsenal** (unlocked at >50k rating)

### 🏢 **Site Mechanics**
- **Interactive Capture Sites** (3 factions)
- **United Nations Sites** (safe zones)
- **HQ Sites** with faction patrols

### 📋 **Task Missions**
- Laptop Download
- Kill/Defend Faction Officer
- Destroy/Defend Faction Bunker

### 👥 **Spawn Zones**
*Randomized squad sizes per faction:*
- **USEC**: 2 + random(5)
- **BEAR**: 2 + random(5)  
- **SCAV**: 2 + random(3)

-Fully scripted medics healing in each group.  
-Fully scripted ticket system updated by scoreside.

# COMPOSITIONS

Here you can find object compositions (pilots with instructions, base with soldiers, squads with objectives...) all integrated with AI scripting. Install mods through steam and look for pbo files, you can extract sqm and sqf script files with [PBO Manager](https://www.moddb.com/mods/pbo-manager) to make Eden compositions that require so.
